# debpalash/homebrew-tap

```sh
brew install debpalash/tap/opal
```

Install VoiceStudio on macOS:

```sh
brew tap debpalash/tap
brew trust --cask debpalash/tap/voicestudio
brew install --cask debpalash/tap/voicestudio
```

The formula tracks [Opal](https://github.com/debpalash/Opal) releases; the cask
tracks [VoiceStudio](https://github.com/debpalash/VoiceStudio) releases.
